# HomeCare Design System

ระบบภาพหลักสำหรับแอป HomeCare ทั้งโหมดลูกค้าและโหมดช่าง รวมถึงเว็บ Dashboard ของผู้ดูแล

## บุคลิก

- น่าเชื่อถือ เป็นมิตร ตรงไปตรงมา
- Flat design ที่เน้นข้อมูลและการตัดสินใจ
- ใช้ภาพผลงานเด่นใน feed แต่ลดภาพรบกวนในขั้นตอนจอง ชำระเงิน และจัดการงาน
- ไม่ใช้ emoji เป็นไอคอน และไม่ผสมไอคอนหลายสไตล์

## ตัวอักษร

- Font family: `Noto Sans Thai`, `sans-serif`
- Body: 16px, line-height 1.5, weight 400
- Supporting text: 14px, line-height 1.5; ห้ามใช้ต่ำกว่า 12px
- Section title: 20–24px, weight 600–700
- Page title: 28–32px, weight 700
- Button: 16px, weight 600

## Layout และองค์ประกอบ

- ใช้ mobile-first และพื้นที่เนื้อหาด้านข้าง 16px
- Spacing scale: 4, 8, 12, 16, 24, 32px
- Card radius: 20px; ขอบบางและเงาเบามาก
- Button radius: 16px; primary action เต็มความกว้างเมื่ออยู่ในขั้นตอนแบบฟอร์ม
- Top-level Mobile screen ใช้ floating bottom navigation radius 28px และเว้น safe area เสมอ
- Touch target อย่างน้อย 44×44px และระหว่างเป้าหมายสัมผัสอย่างน้อย 8px
- Bottom navigation ไม่เกิน 5 รายการ และเว้น safe area ของอุปกรณ์
- ลูกค้าในรุ่นปัจจุบันใช้: หน้าหลัก, คำขอ, งานของฉัน, บัญชี
- ช่างใช้: หางาน, งานของฉัน, สร้างโพสต์, รายได้, บัญชี
- การแจ้งเตือนอยู่บนหัวหน้าจอ และแชตฝั่งช่างเข้าจากงานแทนการเพิ่ม tab
- ใช้ Phosphor Icons แบบ outline เป็นชุดหลัก พร้อม label สำหรับไอคอนที่ความหมายไม่ชัด

## Interaction

- Transition 150–200ms; motion ต้องอธิบายการเปลี่ยนสถานะ ไม่ใช้เพื่อการตกแต่งอย่างเดียว
- รองรับ `prefers-reduced-motion`
- MVP ใช้ Light Mode เท่านั้น แต่ทุกสีต้องอ้างอิง semantic token เพื่อรองรับ Dark Mode ภายหลัง
- รองรับการปรับขนาดตัวอักษรของระบบ และทดสอบ contrast ในสภาพแสงกลางแจ้ง
- ทุก action มี pressed, loading, success และ error feedback
- Forms ใช้ label ที่มองเห็นได้ ตรวจข้อมูลเมื่อออกจากช่อง และแสดงข้อผิดพลาดใกล้ช่องนั้น
- Back navigation ต้องคาดเดาได้และรักษาข้อมูลแบบร่าง

## รูปภาพและ Feed

- รูป feed ใช้อัตราส่วนคงที่และจองพื้นที่ล่วงหน้าเพื่อลด layout shift
- ใช้ thumbnail ที่บีบอัดและโหลดแบบ lazy loading
- โพสต์ต้องแสดงชื่อช่าง สถานะตรวจสอบ หมวดงาน พื้นที่ ราคาอ้างอิงหรือสถานะขอประเมิน และ CTA “ขอใช้บริการ”
- รูปจากงานลูกค้าแสดงสาธารณะได้เมื่อมีความยินยอมและปิดบังข้อมูลส่วนตัวแล้วเท่านั้น
- หน้า Home ลูกค้าเรียงงานปัจจุบันและทางเข้าจองบริการก่อนหมวด ช่างแนะนำ และ feed ผลงาน

## สิ่งที่หลีกเลี่ยง

- Gradient หรือเงาหนักหลายชั้น
- การ์ดทุกส่วนจนลำดับชั้นของข้อมูลหายไป
- สีส้มเป็นสีหลักทั่วทั้งแอป
- ปุ่มไอคอนเล็กหรือไม่มี accessible label
- placeholder ที่ทำหน้าที่แทน label
- การเลื่อนแนวนอนเป็นช่องทางเดียวในการเข้าถึงเนื้อหาหลัก
