# Phase 4A — งานบริการและนัดหมาย

Phase นี้เปลี่ยนข้อตกลงที่ลูกค้าและช่างยืนยันฉบับเดียวกันครบแล้วให้เป็น **งานบริการ** โดยอัตโนมัติและอยู่ในธุรกรรมเดียวกับการยืนยันครั้งสุดท้าย

## ขอบเขตที่ส่งมอบ

- สร้างเลขงานรูปแบบ `HC-YYYYMMDD-NNNNNN` และไม่สร้างงานซ้ำจากคำขอเดียวกัน
- ตรึงขอบเขต ค่าแรง รูปแบบราคา ระยะรับประกัน และอัตราค่าคอมมิชชัน ณ วันที่เปิดงาน
- เริ่มต้นค่าคอมมิชชันที่ 15% ของค่าแรงในตารางตั้งค่าภายใน และไม่คิดจากค่าวัสดุ
- ตรึงวัน ช่วงเวลา และรายละเอียดสถานที่ไว้ในนัดหมายของงานบริการ
- เก็บเหตุการณ์สถานะเป็นประวัติแบบ append-only
- รองรับ transition แบบตรวจ optimistic status สำหรับ `scheduled → cancelled` พร้อมเหตุผล
- ให้เฉพาะลูกค้าและช่างของงานอ่านข้อมูลงานผ่าน RPC; ตาราง public ทั้งสามตารางเปิด RLS และไม่เปิดสิทธิ์ direct access
- หน้ายืนยันข้อตกลงแสดงเลขงาน นัดหมาย และยอดที่เกี่ยวข้องตามบทบาทหลังทั้งสองฝ่ายยืนยันครบ

## สิ่งที่ยังไม่อยู่ใน Phase นี้

- แชตและไฟล์แนบในงาน
- สถานะเดินทาง เริ่มงาน และหลักฐานก่อน/หลัง
- คำขอเพิ่มงาน การตรวจรับ การชำระเงิน และการรับประกัน
- หน้าจอยกเลิกงานสำหรับผู้ใช้ (ฐานข้อมูลและ transition service พร้อมสำหรับเชื่อม UI ในระยะถัดไป)
