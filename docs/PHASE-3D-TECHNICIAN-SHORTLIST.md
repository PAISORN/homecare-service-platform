# Phase 3D — รายชื่อช่าง ใบเสนอราคา และการเลือกช่าง

Phase 3D ต่อจากคำขอที่อยู่สถานะ `matching` โดยยังไม่สร้างงานบริการ นัดหมาย แชต หรือการชำระเงิน

## สิ่งที่รองรับ

- ช่างที่ผ่านการตรวจสอบและมีทักษะตรงหมวดสามารถแสดงความสนใจรับงาน
- งาน `evidence_quote` เปิดให้ช่างส่งขอบเขตงานและค่าแรงแบบปิด ช่างไม่เห็นข้อเสนอของผู้อื่น
- ลูกค้าเห็นรายชื่อช่างที่สนใจสูงสุด 3 คน เรียงจากความพร้อมของใบเสนอราคา ประสบการณ์ และเวลาที่แสดงความสนใจ
- ลูกค้าเลือกช่างได้หนึ่งคนเมื่อมีราคาที่พร้อมใช้
- การเลือกบันทึกราคากับสกุลเงินเป็น snapshot เปลี่ยนคำขอเป็น `technician_selected` และปิดความสนใจของช่างรายอื่น
- งานราคามาตรฐานใช้ `service_items.base_labor_price` เท่านั้น หากราคายังไม่ผ่านการอนุมัติ ปุ่มเลือกช่างจะยังไม่พร้อมใช้งาน

## ขอบเขตความเป็นส่วนตัว

- ฟีดของช่างยังไม่ส่งชื่อ เบอร์โทร ที่อยู่ รหัสสถานที่ รูป หรือข้อความอิสระของลูกค้า
- ช่างเห็นเฉพาะสถานะและเนื้อหาใบเสนอราคาของตัวเอง
- ลูกค้าเจ้าของคำขอเท่านั้นที่เรียกดูรายชื่อช่างได้
- ตารางใบเสนอราคาและผลการเลือกไม่เปิดให้ client อ่านหรือเขียนโดยตรง การทำงานผ่าน RPC ที่ตรวจบทบาทและความเป็นเจ้าของ
- Audit log เก็บรหัสอ้างอิง ราคา และสถานะ แต่ไม่เก็บข้อความขอบเขตงาน

## สถานะและข้อมูลใหม่

- `service_request_status.technician_selected`
- `quotation_status`: `submitted`, `withdrawn`, `accepted`, `declined`
- `quotations`
- `service_request_selections`
- RPC `submit_technician_quotation`
- RPC `list_customer_request_shortlist`
- RPC `select_technician_for_request`

## วิธีทดสอบด้วยสองบัญชี

1. บัญชีลูกค้าสร้างคำขอแบบแจ้งอาการและยืนยันส่งคำขอ
2. บัญชีช่างที่ผ่านการตรวจสอบเปิด “งานที่เหมาะกับคุณ” และกดแสดงความสนใจ
3. ช่างกด “ส่งใบเสนอราคา” กรอกขอบเขตอย่างน้อย 10 ตัวอักษรและค่าแรงมากกว่า 0
4. ลูกค้าเปิด “คำขอรับบริการของฉัน” แล้วกด “ดูรายชื่อช่างที่สนใจ”
5. ตรวจว่าลูกค้าเห็นช่างไม่เกิน 3 คน เห็นราคาและขอบเขตของช่าง แต่ช่างแต่ละคนไม่เห็นข้อเสนอของกันและกัน
6. ลูกค้ากดเลือกช่าง ยืนยันชื่อและราคา แล้วตรวจว่าสถานะคำขอเป็น “เลือกช่างแล้ว”
7. กลับไปบัญชีช่างรายอื่นและตรวจว่าคำขอนี้ไม่เปิดรับความสนใจหรือแก้ใบเสนอราคาอีก

## สิ่งที่ยังไม่รวม

- การเปิดงานบริการและเลขงาน
- การยืนยันขอบเขต ราคา และเวลานัดหมายร่วมกัน
- แชต การชำระเงิน การติดตามสถานะงาน รีวิว รับประกัน และข้อพิพาท
- การจับคู่ตามพื้นที่บริการ ตามคำยืนยันให้ยังไม่ระบุพื้นที่ในระยะนี้
