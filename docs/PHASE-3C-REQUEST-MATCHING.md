# Phase 3C — ส่งคำขอและงานที่เหมาะกับคุณ

Phase 3C เปิดให้ลูกค้ายืนยันส่ง **คำขอรับบริการ** แบบร่างเข้าสู่สถานะกำลังหาช่าง
และเปิด feed **งานที่เหมาะกับคุณ** สำหรับช่างที่ผ่านการตรวจสอบแล้ว ช่างสามารถ
แสดงหรือถอน **ความสนใจรับงาน** ได้ แต่ยังไม่ถือว่าได้รับงานและยังไม่สร้าง
**งานบริการ**

## ขอบเขตที่เปิดใช้

- ลูกค้าส่งคำขอที่ผ่าน Safety Stop และยังใช้หมวด/รายการบริการที่เปิดนำร่อง
- ลูกค้าเห็นสถานะแบบร่างหรือกำลังหาช่าง และยกเลิกคำขอได้ก่อนเลือกช่าง
- ช่างที่ผ่านการตรวจสอบเลือกหมวดทักษะของตนเอง
- feed คัดกรองคำขอตามหมวดทักษะที่ active ฝั่งฐานข้อมูล
- ช่างแสดงหรือถอนความสนใจรับงานได้โดยไม่เห็นความสนใจของช่างรายอื่น
- การ submit, cancel, express interest และ withdraw interest มี Audit Log

## Privacy contract ก่อนจับคู่

`list_matching_service_requests` คืนเฉพาะรหัสคำขอ ชื่อหมวด/รายการ จำนวน
ความเร่งด่วน วันที่/เวลา รูปแบบราคา เวลาส่ง และสถานะความสนใจของช่างคนที่เรียก
ไม่คืน `customer_id`, `service_location_id`, ชื่อ เบอร์โทร ที่อยู่ รูปหน้างาน หรือ
`problem_description` เพราะข้อความอิสระอาจมีข้อมูลติดต่อหรือข้อมูลส่วนบุคคล

ช่างไม่มี RLS สำหรับอ่าน raw row ใน `service_requests` หรือ
`request_attachments` ของลูกค้า การซ่อนใน UI จึงไม่ใช่ authorization boundary

## ขอบเขตที่ยังไม่เปิดใช้

- การคัดกรองตามพื้นที่ ระยะทาง และเวลาว่างของช่าง
- การเปิดเผยรายละเอียดลูกค้าหรือสถานที่ก่อนจับคู่
- shortlist สูงสุด 3 คน การเลือกช่าง และใบเสนอราคา
- การสร้างงานบริการ การนัดหมาย แชต การชำระเงิน และการจ่ายเงินช่าง
- feed โพสต์ผลงานช่างสำหรับลูกค้า

เมื่อเพิ่มพื้นที่ใน phase ถัดไป ต้องใช้ข้อมูลที่ตั้งค่าได้และบังคับ matching rule
ที่ฐานข้อมูล ห้ามฝังชื่อพื้นที่หรือขอบเขตบริการใน UI
