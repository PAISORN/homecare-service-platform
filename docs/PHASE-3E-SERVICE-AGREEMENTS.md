# Phase 3E — ข้อตกลงก่อนเปิดงานบริการ

Phase 3E ต่อจากคำขอที่ลูกค้าเลือกช่างแล้ว โดยให้ลูกค้าและช่างตรวจและยืนยันขอบเขต ค่าแรง สถานที่ และนัดหมายฉบับเดียวกันก่อนเข้าสู่ Phase 4

## สิ่งที่รองรับ

- การเลือกช่างสร้างข้อตกลงจาก snapshot ค่าแรงและขอบเขตของใบเสนอราคาที่ลูกค้าเลือก
- คำขอราคามาตรฐานใช้รายละเอียดรายการบริการเป็นขอบเขตเริ่มต้น
- ลูกค้าหรือช่างเสนอวันที่และช่วงเวลานัดหมายได้
- ทุกครั้งที่เปลี่ยนนัดหมาย ระบบเพิ่ม revision และล้างคำยืนยันเดิมของทั้งสองฝ่าย
- ลูกค้าและช่างยืนยันแยกกัน โดยจะถือว่าครบเมื่อทั้งคู่ยืนยัน revision เดียวกัน
- ข้อตกลงที่ยืนยันครบแล้วแก้ไขไม่ได้ และบันทึกเหตุการณ์สำคัญใน Audit Log
- หลังเลือกช่างแล้ว ช่างที่ถูกเลือกเท่านั้นจึงเห็นชื่อและสถานที่รับบริการผ่าน RPC เฉพาะงาน

## ขอบเขตความปลอดภัย

- ตาราง `service_request_agreements` เปิด RLS แต่ไม่ให้ client อ่านหรือเขียนโดยตรง
- RPC ตรวจว่าผู้เรียกเป็นลูกค้าของคำขอหรือช่างที่ถูกเลือกและบัญชียัง active
- กล่องงานที่เลือกช่างแล้วเปิดเฉพาะช่างที่ผ่านการตรวจสอบ
- นัดหมายต้องเป็นวันนี้หรืออนาคต และช่วงเวลาต้องมีความยาว 1–80 ตัวอักษร
- Audit Log ไม่เก็บขอบเขตงาน ที่อยู่ หรือข้อความอิสระ

## สถานะและข้อมูลใหม่

- `service_request_agreements`
- RPC `get_service_request_agreement`
- RPC `list_technician_selected_requests`
- RPC `propose_service_request_appointment`
- RPC `confirm_service_request_agreement`

คำขอยังคงอยู่สถานะ `technician_selected` แม้ยืนยันครบแล้ว โดย `fully_confirmed_at` เป็นเงื่อนไขพร้อมเข้าสู่ Phase 4

## วิธีทดสอบด้วยสองบัญชี

1. ลูกค้าเลือกช่างจากรายชื่อช่างที่สนใจ แล้วเปิด “คำขอรับบริการของฉัน”
2. กด “ตรวจและยืนยันข้อตกลง” ตรวจขอบเขต ค่าแรง ชื่อสถานที่ และที่อยู่
3. เลือกวันที่นัดหมาย กรอกช่วงเวลา แล้วกด “เสนอเวลานัดหมาย”
4. ลูกค้ากด “ยืนยันข้อตกลงฉบับนี้” และตรวจว่าสถานะลูกค้าเป็น “ยืนยันแล้ว”
5. สลับเป็นบัญชีช่าง เปิด “งานที่เหมาะกับคุณ” แล้วเปิดรายการใน “ข้อตกลงที่ต้องตรวจสอบ”
6. ให้ช่างแก้ช่วงเวลาและบันทึก ตรวจว่าคำยืนยันลูกค้ากลับเป็น “รอยืนยัน”
7. ให้ช่างยืนยัน revision ใหม่ จากนั้นสลับกลับให้ลูกค้ายืนยันอีกครั้ง
8. ตรวจว่าหน้าแสดง “ทั้งสองฝ่ายยืนยันแล้ว” และไม่สามารถแก้นัดหมายได้
9. ปิดแอปแล้วเปิด deep link ของหน้าข้อตกลงโดยตรง ตรวจว่าปุ่มย้อนกลับกลับไปหน้าคำขอหรือหน้างานช่างได้โดยไม่มี `GO_BACK` error

## สิ่งที่ยังไม่รวม

- การสร้างงานบริการ เลขงาน และ snapshot คอมมิชชัน
- ตารางนัดหมายและประวัติสถานะงานแบบ append-only
- แชต แจ้งเตือน การชำระเงิน หลักฐานหน้างาน และ PIN
- การจับคู่ตามพื้นที่บริการ ตามคำยืนยันให้ยังไม่ระบุพื้นที่ในระยะนี้
