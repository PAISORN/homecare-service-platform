# Phase 4B — การติดตามและปฏิบัติงานบริการ

Phase นี้ทำให้งานบริการที่เปิดแล้วติดตามได้จากทั้งบัญชีลูกค้าและบัญชีช่าง พร้อมบังคับลำดับสถานะปฏิบัติงานและการยกเลิกที่ตรวจสอบย้อนหลังได้

## ขอบเขตที่ส่งมอบ

- หน้ารายการงานของลูกค้าและช่าง แยกทางเข้าตามบทบาทและแสดงเฉพาะงานที่บัญชีนั้นเป็นคู่สัญญา
- หน้ารายละเอียดงานที่แสดงเลขงาน ขอบเขต นัดหมาย สถานที่ ราคา และประวัติสถานะ
- ลำดับสถานะของช่าง `scheduled → technician_en_route → technician_arrived → in_progress`
- การเปลี่ยนสถานะใช้ expected status เพื่อกันการเขียนทับข้อมูลที่เปลี่ยนจากอีกอุปกรณ์
- ลูกค้ายกเลิกได้เฉพาะก่อนช่างเริ่มเดินทาง; ช่างยกเลิกได้ก่อนถึงหน้างาน
- ทุกการยกเลิกต้องมีเหตุผล 10–500 ตัวอักษร ยกเลิกนัดหมายในธุรกรรมเดียวกัน และแสดงเหตุผลแก่คู่สัญญา
- เหตุผลอิสระไม่ถูกคัดลอกลง audit metadata; ประวัติสถานะยังเป็น append-only
- RPC รายการ รายละเอียด ประวัติ และ transition ตรวจ active account กับสิทธิ์คู่สัญญาฝั่งฐานข้อมูล
- ตารางงาน นัดหมาย และประวัติยังไม่เปิด direct access ให้ client

## ขอบเขตที่ยังไม่รวม

- แชตและไฟล์แนบระหว่างลูกค้ากับช่าง
- รูปหลักฐานก่อนเริ่มงานและหลังเสร็จงาน
- คำขอเพิ่มงาน การตรวจรับ การชำระเงิน การคืนเงิน และค่าธรรมเนียมยกเลิก
- สถานะหลัง `in_progress` เช่น รอตรวจรับ เสร็จสิ้น ข้อพิพาท และรับประกัน

ค่าธรรมเนียมหรือผลทางการเงินจากการยกเลิกจะไม่ถูกคำนวณใน Phase นี้ จนกว่านโยบายการชำระเงินและคืนเงินจะได้รับการยืนยันและมี ledger รองรับ
